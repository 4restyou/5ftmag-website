# 기사 수정·발행 점검표

이 점검표는 C01(전시 정보), C02(이미지 출처와 사용 근거), C03(다국어 발행 동등성)을 다룬다.
기존 운영 기준은 [editorial-operations.md](editorial-operations.md)를 따른다.

## 전시 정보

- [ ] 작가·전시명, 기간, 장소·주소를 원문 안내와 대조한다.
- [ ] 관람시간·휴관, 가격·예약, 공식 출처 URL과 실제 확인일을 기록한다.
- [ ] 모르는 항목은 `확인 필요`로 남긴다. 월까지만 공개된 종료일에 임의의 날짜를 붙이지 않는다.
- [ ] 긴 모음에는 기간·장소 요약과 각 전시로 가는 이름 있는 링크를 둔다. 지난달 중복 전시도 현재 기간·장소와 이전 기사 링크를 남긴다.
- [ ] 요약은 본문에서 확인된 사실만 옮긴다. 방문 전 변경 여부 확인은 별도 업무다.

2026년 10월 기사에 추가한 요약은 기존 본문의 16개 주요 항목을 옮겼다. 로저 발렌의 종료일은
`2027-02`까지만 기재한다. 관람시간·휴관·가격·예약·상세 주소가 없는 항목은 확인이 필요하다.
이 작업일은 외부 공식 안내를 새로 확인한 날짜가 아니다.

## 이미지 기록

- [ ] 파일별 원출처 URL, 작가 또는 기관, 실제 이미지 제작자, 제공·확인 경위와 캡션을 기록한다.
- [ ] 공개 게시물에서 확인한 이미지에 `제공`이나 `승인`이라고 쓰지 않는다.
- [ ] 사용 근거는 출처와 분리해 기록한다. 승인·라이선스의 증거와 웹·번역판·썸네일 등 적용 범위를 확인한다.
- [ ] 제작자·전달 경위·승인 범위가 모르면 `null`, 사용 상태는 `unknown`으로 남기고 후속 확인을 배정한다.
- [ ] 캡션과 JPG/WebP 참조를 바꿀 때 감사 기록도 함께 검토한다. 이미지 내용 교체는 기존 파일을 덮어쓰지 않는다.

`data/editorial-assets.json`은 이 10월 기사만의 수동 감사 원장이다. 11개 이미지 묶음의
JPG/WebP 22개 경로와 세 언어 캡션의 출처 부분을 기록했다. 전시에 등장하는 작가는 `subject`에
적었으며, 그 사람이 해당 포스터의 제작자나 권리자라고 추정하지 않았다. `source.url: null`은
원출처 페이지를 모른다는 뜻이다. 기재된 Threads·피크닉 URL도 기존 기사에서 옮긴 값이다.

`reviewed.source: true`는 **현재 기사와 원장의 출처 표기를 대조했다**는 뜻이다.
`reviewed.use: true`는 **근거를 검토해 미확인 상태까지 기록했다**는 뜻이다.
둘 다 사용 승인이나 법적 적합성 판정이 아니다. 이번 11개 묶음은 모두 `use.status: unknown`이다.
`auditDate`는 저장소 기준 검토일이며 `auditBasis`에 검토 범위를 적는다.

`use.status: confirmed`로 바꾸려면 `evidence`에 증거 위치, `scope`에 실제 허용 범위를 적고
담당 편집자가 검토한다. 공개 URL만으로 승인 상태를 확정하지 않는다. 내부 증거에 개인정보가
있다면 내용을 공개 저장소에 넣지 않고 내부 기록 번호만 남긴다.

## KO/EN/JA 동등성

- [ ] 기사 식별자, 발행일·수정일, 분류, 표시 날짜, canonical·hreflang과 댓글 식별자가 일치한다.
- [ ] 요약과 본문 기간, 요약의 표시 날짜와 `time datetime`, 전시 ID와 링크 목적지를 대조한다.
- [ ] 내부 기사 링크는 같은 언어판에 연결하고 공식 외부 출처는 같은 URL로 유지한다.
- [ ] 이미지 경로, 대체 텍스트, 캡션 출처를 세 언어에서 확인한다. 인명·공식 제목의 의도된 표기는 보존한다.
- [ ] Yoo Seung-ho의 `BLUE HOUR`와 Yu Hwa Jung의 `FACES OF ALL THINGS`는 별개 전시다. 관련 기사나 포스터를 혼동하지 않는다.
- [ ] 번역 안내, 실제 공개 상태와 수정 반영 여부를 확인한다. 정적 파일만으로 DB 공개 override를 판정하지 않는다.
- [ ] 좁은 화면과 키보드에서 요약 펼치기·링크 이동·포커스와 고정 헤더 가림을 확인한다.

`<base href="/">`가 있으므로 전시 바로가기는 `#id`만 쓰지 않고
`/en/stories/oct-2026-exhibitions.html#id`처럼 해당 언어 기사 경로를 포함한다.

## 검증

```sh
node scripts/check-editorial-content.mjs
npm run test:unit -- tests/unit/editorial-content.spec.mjs
```

검사기는 10월 기사 세 파일과 선언된 이미지 원장만 읽는다. `stories.json`의 해당 항목을 읽어서
발행일·분류를 대조하지만 수정하거나 생성하지 않는다. ID 중복·누락, 기간·분류·링크 차이,
출처 캡션 누락, 원장 미등록 이미지, 검토 플래그 누락, 증거 없는 승인 선언은 실패한다.
원장의 `unknown` 사용 상태는 후속 점검 경고이며 종료 코드는 0이다. 과거 60여 편에
라이선스 기록을 소급 강제하거나 이미지를 삭제하는 검사가 아니다.

이 검사는 외부 링크의 운영 여부, 전시 사실의 최신성, 번역 문장 품질, 실제 권리나 DB 공개 상태를
보장하지 않는다. 새 기사까지 검사 범위를 넓힐 때는 먼저 원장 범위와 검토 책임을 합의한다.
발행 전 자산 검사·다국어 검사·QA와 최종 운영 화면 확인은 별도로 수행한다.
