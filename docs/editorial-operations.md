# 편집·운영 기준

5ft magazine은 정기 발행일이나 응모 마감일을 약속하지 않는다.
대신 방문자가 다시 올 이유가 사라지지 않도록 아래 신호를 운영 기준으로 사용한다.

## 콘텐츠 우선순위

1. 필름 정보와 실제 촬영 결과
2. 필름·사진에 관한 Articles
3. 독자 사진 참여와 현재 호 주제
4. Magazine 소개와 구매
5. Market·Labs·Shop 보조 서비스

새 기능을 제안할 때는 위 다섯 항목 중 어느 축을 강화하는지 먼저 적는다.
어느 축에도 해당하지 않으면 기능보다 기사·사진 정리를 우선한다.

## 약속 없는 운영 리듬

- 새 글이 없어도 최근 독자 사진과 랜덤 추천 필름이 홈을 갱신한다.
- 45일 이상 새 글이 없으면 기존 글 재편집, 필름 묶음, 짧은 편집부 소식 중 하나를 검토한다.
- 현재 호 응모를 받을 때만 `current-theme.json`을 활성화한다.
- 유지할 수 없는 뉴스레터는 계속 숨기며, 실제 발송 체계가 준비된 뒤에만 다시 노출한다.
- 발행일·마감일은 확정할 수 있을 때만 화면에 표시한다.

`npm run content:health`는 최근 발행량, 주제 분포, 현재 호 활성 상태를 보여준다.
이 명령은 경고만 제공하며 발행을 강제하지 않는다.

## 이미지 사용 근거 후속 확인

[기사 수정·발행 점검표](editorial-checklist.md)와 `data/editorial-assets.json`을 기준으로
출처 표기와 사용 허락을 별개로 확인한다. 2026-10-03 후속 대조에서 누락됐던
Photo Art 출처 9건을 공개 원문과 JPEG SHA-256 일치로 확인하고 세 언어 캡션에
연결했다. 현재 10월 전시 기사 이미지 11개 묶음·22개 JPG/WebP 경로 중
원출처 URL 누락은 **0개**이며, **11개 모두 `use.status: unknown`**이다.
공개 게재 출처 확인은 원저작자 확인이나 사용 허락을 뜻하지 않는다.

1. 묶음별 담당 편집자·확인 기한을 내부 후속 원장에 배정한다. 현재 배정/승인 완료로
   표시하지 않는다. 출처를 확인한 Photo Art 9개와 기존 Threads·피크닉 2개 모두
   사용 근거 후속 확인 대상이다.
2. 원문 페이지와 해당 이미지의 일치 여부, 실제 제작자·권리자, 전달 경위와 실제
   확인일을 확인한다. 공개 URL 발견은 출처 증거일 뿐이다. 전시 작가나 캡션에 적힌
   기관을 포스터 제작자/권리자로 추정하지 않는다. 기존 Threads·피크닉 URL 2개도
   사용 허락의 증거가 아니며 별도 확인 대상으로 남긴다.
3. 허락 회신이나 명시된 라이선스를 권한 제한된 off-repo 기록에 보관한다. 이미지
   묶음/파일과 연결하고 웹 본문·KO/EN/JA 번역판·썸네일·OG/공유 이미지·크롭/WebP
   변환의 허용 여부, 표기 조건·유효 기간을 각각 기록한다. 개인정보·메일 전문·서명
   URL은 공개 Git에 넣지 않는다. 연락이나 문의 발송도 담당자의 별도 승인 업무다.
4. 담당 편집자가 권한 근거와 실제 사용 범위의 일치를 확인한 뒤에만 원장 변경을
   요청한다. `confirmed`는 `use.evidence`의 내부 기록 번호와 `use.scope`의 명시된
   허용 범위가 필요하다. 대기·무응답·범위 부족은 `unknown`으로 유지한다.
   현 검사기는 `unknown`일 때 evidence/scope가 `null`이어야 하므로 문의 중 자료는
   내부 후속 원장에만 보관한다. `reviewed: true`와 검사 성공은 승인 표시가 아니다.
5. 승인된 콘텐츠 작업에서만 원장과 세 언어 캡션·본문/썸네일/OG 참조를 함께 대조하고
   `node scripts/check-editorial-content.mjs`를 실행한다. 교체가 필요하면 새 파일명을
   사용한다. 이미지 숨김·삭제·교체와 기존 기사 수정은 자동 수행하지 않는다.

후속 작업에서 원장 URL과 기사 캡션 링크를 보완했으며 이미지 파일은 바꾸지 않았다.
실제 허락 증거가 확보될 때까지 11개 `unknown`을 유지한다. 후속 완료는 담당자와 기한,
제한된 증거 번호, 검토 결과로 기록하며 출처를 찾은 것과 사용 근거 확정을 따로 센다.

## 정보 구조 측정

다음 익명 이벤트로 30일 단위 사용 흐름을 확인한다.

- `nav_clicked`: Articles·Films·Magazine·Market·More 실제 이용 비율
- `film_finder_searched`: PC 홈 필름 검색 사용량
- `film_finder_recommendation_clicked`: 추천 필름 진입량
- `shop_magazine_link_clicked`: Shop에서 Magazine으로 이동한 횟수

판단 기준은 절대 클릭 수보다 페이지뷰 대비 비율이다. More 안의 메뉴 사용이 지속적으로
높으면 상단 복귀를 검토하고, 낮다는 이유만으로 페이지를 삭제하지 않는다.

## 월 1회 점검

- 최근 글과 사진이 홈에서 정상 노출되는가
- Film Finder 검색 결과가 실제 필름을 찾는가
- 현재 호 문구와 응모 상태가 일치하는가
- Magazine의 미리보기·열람·구매 링크가 유효한가
- Shop의 책 상품에서 “이 호의 내용 보기”가 연결되는가
- Market 신고·개인정보 보호 정책이 정상인가
- `npm run qa`, `npm run db:audit`, `npm run content:health`가 정상인가
