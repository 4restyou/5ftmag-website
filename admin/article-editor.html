기사 발행 안내

구형 에디터 지원 종료
운영 홈 기사 목록 투고 검토 이주의 사진 매물 신고 메시지 댓글 공지 카탈로그 카메라 브랜드 필름 카탈로그 현상소 수리실 웹진 이북 Shop 분석 통계

이 에디터에서는 기사를 작성하거나 발행할 수 없습니다.

구형 에디터는 현재 기사·공통 셸·번역 발행 체계와 호환되지 않아 지원을 종료했습니다. 새 기사와 기존 본문 수정은 저장소 작업으로 진행합니다.

  1. 편집 담당자에게 원고·사진 또는 기존 기사 URL과 수정 내용을 전달합니다.
  2. 저장소의 new-article 절차로 한국어·영문·일문 기사와 목록 정보를 함께 준비합니다.
  3. 공통 셸·이미지·번역·RSS·사이트맵을 검수하고, PR의 CI 통과 후 승인된 내용을 머지·배포합니다.
  4. 예약 발행은 자동 지원하지 않습니다. 공개할 시점에 검수된 PR을 머지합니다. 미래 날짜 입력만으로 예약되지 않습니다.

여기서는 초안을 불러오거나 저장하지 않으며 GitHub 토큰을 받지 않습니다. 기존 초안 데이터는 삭제하지 않았으므로 필요하면 담당자에게 복구를 요청하세요.
